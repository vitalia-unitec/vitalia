# Vitalia

Directorio web de veterinarias que conecta a dueños de mascotas con clínicas cercanas y confiables. Proyecto de la Universidad Tecnológica de México, UNITEC.

## Estructura del repo

| Carpeta | Equipo | Contenido |
|---|---|---|
| `backend/` | Backend | API en Python con FastAPI |
| `frontend/` | Frontend | Página web |
| `db/` | Base de datos | Scripts SQL en dialecto SQLite |
| `infra/` | Infraestructura | Configuración de Apache, despliegue y scripts |
| `docs/` | Todos | Contrato de la API y documentos del proyecto |

## Documentos clave

- [Contrato de la API v1.1](docs/Vitalia_Contrato_API_v1.1.pdf): rutas, formatos y acuerdos entre equipos.
- [Cómo trabajamos](CONTRIBUTING.md): ramas, commits, pull requests e issues.

## Cómo nos comunicamos

- **Issues** para tareas, errores y dudas entre equipos.
- **Projects** para ver el avance en el tablero.
- **Pull requests** para revisar código antes de mezclarlo.
- **Discussions** para avisos generales y decisiones.
